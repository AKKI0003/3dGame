This project is still in the development phase.

Unity hub and C# is being used to develop this game. 
It is an Indie linear walkthrough story base game set in Delhi itself. 
Basic mechanics like use of keyboard and Basic UI has been developed like 
-player interaction 
-opening and closing of a letter which contains content on how to play the game
-a basic delhi metro station structure has been laid out which will be worked upon later 
-player movements have been furnished

# Delhi Story

A narrative Unity game based on real memories.

## Story

As the story progresses, players goes to real locations in Delhi
like Metro rides, Janpath walks, and skating sessions.

## Built With

Unity 6
